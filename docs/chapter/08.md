# Chapter 8 – Loops

## 1. Introduction

Session 8 introduces loops.

Loops allow programs to repeat operations.

The focus is on:

- looping through arrays
- `for` loops
- enhanced `for` loops
- `while` loops
- `do-while` loops
- array traversal
- shifting array elements

Loops are essential when working with collections of data.

---

## 2. Why Loops?

Without loops, repeated operations become inefficient.

Less good:

```java
sum += grades[0];
sum += grades[1];
sum += grades[2];
```

Better:

```java
for (int i = 0; i < size; i++)
{
  sum += grades[i];
}
```

Loops allow the same operation to be repeated systematically.

---

## 3. The for Loop

The `for` loop is commonly used when the number of repetitions is known.

Example:

```java
for (int i = 0; i < size; i++)
{
  sum += grades[i];
}
```

A `for` loop contains:

- initialization
- condition
- update

Example:

```java
for (int i = 0; i < size; i++)
```

---

## 4. Loop Variables

The loop variable often represents an index.

Example:

```java
int i
```

The loop variable changes during each iteration.

Example:

```text
0 → 1 → 2 → 3
```

Indexes are often used when traversing arrays.

---

## 5. Traversing Arrays

Traversing means visiting array elements one by one.

Example:

```java
for (int i = 0; i < size; i++)
{
  System.out.println(grades[i]);
}
```

Usually, loops should only process the added elements.

Therefore:

```java
i < size
```

is often correct.

Not:

```java
i < grades.length
```

when unused positions exist.

---

## 6. Calculating Values with Loops

Loops are often used for calculations.

Example:

```java
public int sumOfGrades()
{
  int sum = 0;

  for (int i = 0; i < size; i++)
  {
    sum += grades[i];
  }

  return sum;
}
```

The loop accumulates values step by step.

---

## 7. Searching with Loops

Loops can search for specific values.

Example:

```java
public boolean anyFailedGrades()
{
  for (int i = 0; i < size; i++)
  {
    if (grades[i] <= 0)
    {
      return true;
    }
  }

  return false;
}
```

The loop checks each element.

---

## 8. Finding Minimum Values

Loops can compare values.

Example:

```java
public int getMinimumGrade()
{
  int min = grades[0];

  for (int i = 1; i < size; i++)
  {
    if (grades[i] < min)
    {
      min = grades[i];
    }
  }

  return min;
}
```

Important idea:

- start with an initial value
- update when a smaller value is found

---

## 9. Enhanced for Loop

The enhanced `for` loop simplifies traversal.

Example:

```java
for (int grade : grades)  // traversing all array elements
{
  sum += grade;
}
```
> Note: This only works for arrays, if the array is full. 

Advantages:

- simpler syntax
- easier to read
- no explicit index needed

After Session 8:

- use enhanced `for` loops when indexes are unnecessary
- use indexed `for` loops when indexes are needed

---

## 10. Limitations of Enhanced for Loops

Enhanced `for` loops cannot easily:

- access indexes
- modify array structure
- shift elements

Example where indexed loops are needed:

```java
for (int i = index; i < size - 1; i++)
{
  grades[i] = grades[i + 1];
}
```

---

## 11. The while Loop

A `while` loop repeats while a condition is true.

Example:

```java
while (seconds > 0)
{
  tick();
}
```

The condition is checked before each iteration.

A `while` loop may execute zero times.

---

## 12. The do-while Loop

A `do-while` loop executes at least once.

Example:

```java
do
{
  goOneFloorUp();
}
while (currentFloor < floor);
```

The condition is checked after each iteration.

---

## 13. Loop Structures Overview

### for Loop

Used when the number of iterations is known.

Example:

```java
for (int i = 0; i < size; i++)
```

### Enhanced for Loop

Used for simple traversal. For arrays, when the array is full or combined with an extra condition.

Example:

```java
for (int grade : grades)
```

### while Loop

Used when repetition depends on a condition.

Example:

```java
while (seconds > 0)
```

### do-while Loop

Used when at least one iteration is required.

Example:

```java
do { ... } while (...)
```

---

## 14. Removing Elements from Arrays

Removing an element requires shifting.

Example:

```java
public void removeGrade(int index)
{
  for (int i = index; i < size - 1; i++)
  {
    grades[i] = grades[i + 1];
  }

  size--;
}
```

Elements are copied left.

The gap disappears.

---

## 15. Adding Elements at an Index

Adding elements may also require shifting.

Example:

```java
public void addGrade(int index, int grade)
{
  for (int i = size; i > index; i--)
  {
    grades[i] = grades[i - 1];
  }

  grades[index] = grade;
  size++;
}
```

Elements are copied right.

Important:

- shifting often requires looping backwards

---

## 16. Resizable Arrays

Arrays have fixed length.

A larger array may be created when capacity is full.

Example:

```java
private void doubleTheArrayLength()
{
  int[] newArray = new int[grades.length * 2];

  for (int i = 0; i < size; i++)
  {
    newArray[i] = grades[i];
  }

  grades = newArray;
}
```

The old values are copied into the new array.

---

## 17. Loops and Responsibility

Loops often belong inside collection-like classes.

Example:

```java
gradeList.sumOfGrades()
```

instead of exposing arrays externally.

The class should manage:

- traversal
- searching
- calculations
- shifting

---

## 18. Testing Loop Logic

Loop-based methods should be tested carefully.

Example:

```java
@Test void minimumGrade()
{
  GradeList list = new GradeList(4);

  list.addGrade(12);
  list.addGrade(7);
  list.addGrade(10);

  assertEquals(7, list.getMinimumGrade());
}
```

Tests should include:

- empty structures
- single elements
- multiple elements
- boundary indexes

---

## 19. Typical Beginner Mistakes

Common mistakes:

1. Off-by-one errors
2. Using `<=` instead of `<`
3. Forgetting to update the loop variable
4. Looping over unused array positions
5. Forgetting to decrement or increment `size`
6. Traversing in the wrong direction during shifting
7. Infinite loops

## Summary

Session 8 introduces loops and array traversal.

Important ideas include:

- loops repeat operations
- indexed `for` loops work well with arrays
- enhanced `for` loops simplify traversal
- `while` and `do-while` loops support condition-based repetition
- loops can calculate, search, and shift data
- arrays often require shifting during insertion and removal
- resizable arrays require copying elements

Loops are essential for working with collections and data structures.
