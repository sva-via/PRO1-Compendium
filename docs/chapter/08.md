---

## 2. Hvad er en relation?

En relation beskriver, hvordan to klasser hænger sammen.

Eksempler:

- En `Song` har en varighed (`Time`)  
- En `Person` har en fødselsdato (`MyDate`)  

En relation betyder, at et objekt:
- refererer til et andet objekt  
- samarbejder med det  
- evt. “ejer” det  

---

## 3. Første eksempel – samarbejde

```java
public class Time {
  private int seconds;

  public Time(int seconds) {
    if (seconds < 0) {
      throw new IllegalArgumentException();
    }
    this.seconds = seconds;
  }

  public int getSeconds() {
    return seconds;
  }
}
```

```java
public class Song {
  private String title;
  private Time duration;

  public Song(String title, Time duration) {
    if (duration == null) {
      throw new IllegalArgumentException();
    }
    this.title = title;
    this.duration = duration;
  }

  public int getDurationInSeconds() {
    return duration.getSeconds();
  }
}
```

Her samarbejder `Song` med `Time`.

Dette kaldes **delegation** – Song overlader arbejdet til Time.

---

## 4. Typer af relationer

Vi kan beskrive relationer med tre begreber:

### Association
Objekter refererer til hinanden.

- kan eksistere uafhængigt  
- fx: Car → Person  

### Aggregation
“Del af”, men delen kan eksistere selv.

- svagt ejerskab  
- fx: Car → Wheel  

### Composition
Stærkt ejerskab.

- delen giver ikke mening alene  
- fx: Person → MyDate  

---

## 5. Sammenligning

| Type        | Kan eksistere alene? | Ejerskab | Eksempel |
|-------------|---------------------|----------|----------|
| Association | Ja                  | Nej      | Car–Person |
| Aggregation | Ja                  | Svagt    | Car–Wheel |
| Composition | Nej                 | Stærkt   | Person–MyDate |

---

## 6. Ejerskab

Ejerskab handler om:

- hvem der har ansvar  
- hvem der styrer livscyklus  
- om objekter giver mening alene  

Spørg:

> Giver dette objekt mening uden det andet?

---

## 7. Invariant i relationer

Relationer introducerer nye regler:

- må være null?  
- må deles?  
- må ændres?  

Eksempel:

```java
if (duration == null) {
  throw new IllegalArgumentException();
}
```

---

## 8. Test af relationer

```java
@Test
void getDurationInSeconds_returnsCorrectValue() {
  Time time = new Time(120);
  Song song = new Song("Test", time);

  assertEquals(120, song.getDurationInSeconds());
}
```

Test:

- normale tilfælde  
- grænsetilfælde  
- ugyldige input  

---

## 9. Mutable vs immutable

Hvis objekter er mutable, kan de påvirke hinanden.

```java
MyDate date = new MyDate(...);
Person p1 = new Person(date);
Person p2 = new Person(date);
```

Ændring ét sted påvirker begge.

---

## 10. Defensive copying

```java
public Person(MyDate birthDate) {
  this.birthDate = new MyDate(birthDate);
}

public MyDate getBirthDate() {
  return new MyDate(birthDate);
}
```

Bruges når objekter er mutable.

## 11. Designprincipper

- relationer skal give mening i domænet  
- invariant gælder også her  
- undgå delt mutable state  
- ansvar skal være tydeligt
