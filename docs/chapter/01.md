# Chapter 1 – What Is an Object?

## 1. Introduction

The main goal of object-oriented programming is to model concepts from a problem domain as software objects.

In PRO1, the focus is not primarily on learning Java syntax, but on learning how to think in terms of:

- objects
- responsibilities
- state
- behavior

An object represents a concept that:

- stores information
- performs operations
- collaborates with other objects

---

## 2. Objects in the Real World and in Software

Real-world objects:

- have a state
- can perform actions
- may affect other objects

Software objects work in a similar way.

Example:

```java
Counter counter = new Counter();
counter.increment();
```

A `Counter` object stores a value and can increase it.

The object remembers its own value internally.

---

## 3. Variables and Objects

A variable can store a primitive value:

```java
int number = 5;
```

A variable can also store a reference to an object:

```java
Temperature temp = new Temperature(20.0);
```

Important:
- `temp` is a variable
- the `Temperature` object is created with `new`

The variable refers to the object.

---

## 4. Classes as Models

A class describes:
- what data objects store
- what operations objects can perform

Example:

```java
public class Temperature
{
  private double celsius;

  public Temperature(double celsius)
  {
    this.celsius = celsius;
  }

  public double getCelsius()
  {
    return celsius;
  }

  public double getKelvin()
  {
    return celsius + 273.15;
  }
}
```

The class models the concept of a temperature.

---

## 5. State and Behavior

The state of an object is stored in instance variables (fields).

Example:

```java
private double celsius;
```

Behavior is implemented using methods.

Example:

```java
public double getKelvin()
{
  return celsius + 273.15;
}
```

The object is responsible for performing operations on its own data.

---

## 6. Constructors

A constructor initializes a newly created object.

Example:

```java
public Temperature(double celsius)
{
  this.celsius = celsius;
}
```

The constructor ensures that the object starts with an initial state.

Objects are created using `new`:

```java
Temperature temp = new Temperature(20.0);
```

---

## 7. Methods

Methods define the operations an object can perform.

Examples:
- changing state
- returning information
- calculating values

```java
public int getValue()
{
  return value;
}
```

```java
public void increment()
{
  value++;
}
```

Some methods return values.
Some methods modify the object's state.

---

## 8. Boolean Methods

A method may return a boolean value.

Example:

```java
public boolean isZero()
{
  return value == 0;
}
```

Boolean methods typically answer questions about the object.

---

## 9. Testing Objects with JUnit

Objects are tested by:
1. creating objects
2. calling methods
3. checking results

Example:

```java
@Test void incrementOnceReturns1()
{
  Counter counter = new Counter();
  counter.increment();

  assertEquals(1, counter.getValue());
}
```

Testing focuses on the observable behavior of the object.

---

## 10. Primitive Types Used in Session 1

Session 1 mainly uses:
- `int`
- `double`
- `boolean`

Examples:

```java
private int value;
private double celsius;
```

---

## 11. Typical Beginner Mistakes

Common mistakes:

1. Confusing an object with a variable
2. Forgetting to create the object using `new`
3. Putting logic outside the object
4. Forgetting that objects store state

---

## 12. Reflection Questions

- What is the difference between a class and an object?
- What is the responsibility of a constructor?
- What is the difference between state and behavior?
- Why are methods part of the object?
- What does a boolean method represent?

---

## Summary

An object:

- models a concept
- stores state
- provides behavior
- is created from a class
- is responsible for its own operations

Object-oriented programming is about designing meaningful objects and assigning responsibilities correctly.
