# Kapitel 10 – equals, identitet og lighed

## 1. Introduktion

Når vi arbejder med objekter, opstår et vigtigt spørgsmål:

> Hvornår er to objekter “ens”?

Dette kapitel handler om:

- forskellen på identitet og lighed  
- hvordan equals bruges  
- hvordan det påvirker design og test  

---

## 2. Identitet vs lighed

I Java findes to måder at sammenligne objekter:

```java
a == b
```

og

```java
a.equals(b)
```

### Identitet (==)

Tjekker om to referencer peger på samme objekt.

### Lighed (equals)

Tjekker om to objekter har samme indhold.

---

## 3. Eksempel

```java
Name n1 = new Name("Ada", "Lovelace");
Name n2 = new Name("Ada", "Lovelace");
```

```java
n1 == n2      // false
n1.equals(n2) // true (hvis equals er korrekt implementeret)
```

---

## 4. Implementering af equals

```java
@Override
public boolean equals(Object obj) {
  if (this == obj) return true;
  if (obj == null) return false;
  if (getClass() != obj.getClass()) return false;

  Name other = (Name) obj;

  return firstName.equals(other.firstName)
      && lastName.equals(other.lastName);
}
```

---

## 5. Invariant og equals

equals skal være konsistent med klassens invariant.

Hvis to objekter er “ens”, skal deres state være gyldig.

---

## 6. Test af equals

```java
@Test
void equals_sameValues_returnsTrue() {
  Name n1 = new Name("Ada", "Lovelace");
  Name n2 = new Name("Ada", "Lovelace");

  assertTrue(n1.equals(n2));
}
```

Test også:

- forskellige værdier  
- null  
- samme objekt

## 7. Brug i samlinger

equals bruges fx i:

```java
list.contains(obj)
list.remove(obj)
```

👉 Derfor er korrekt equals vigtig.
