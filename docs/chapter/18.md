```text

↓

ViewControllers
↓

ViewHandler
↓

Model Interface
↓
```

```text
Interaction
```

```text
Business responsibility
```

## 3. ViewController Structure

Each window should have:

- one FXML file
- one ViewController

Example:

```text
LoginView.fxml
↓
LoginViewController
```

A ViewController typically contains:

- FXML variables
- event methods
- Model reference
- ViewHandler reference
- root node reference

Example:

```java
private Model model;

private ViewHandler viewHandler;

private Region root;
```

Responsibility stays local.

:contentReference[oaicite:2]{index=2}

## 4. init Method

ViewControllers use an initialization method.

Example idea:

```java
public void init(
    ViewHandler viewHandler,
    Model model,
    Region root)
{
  this.model = model;
  this.viewHandler = viewHandler;
  this.root = root;
}
```

Purpose:

- connect ViewHandler
- connect model
- connect root node

FXML creates controls.

The application connects responsibilities afterwards.

## 7. Example ViewState

Example:

```java
public class ViewState
{
  private int sharedValue1;

  private String sharedValue2;

  public ViewState()
  {
    sharedValue1 = -1;
    sharedValue2 = null;
  }

  public void setSharedValue1(
      int value)
  {
    sharedValue1 = value;
  }

  public int getSharedValue1()
  {
    return sharedValue1;
  }
}
```

One ViewController:

```text
Stores data
```

Another ViewController:

```text
Reads data
```

Responsibility remains separated.
