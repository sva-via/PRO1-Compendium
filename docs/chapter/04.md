# Chapter 4 – Selections

## 1. Introduction

Session 4 introduces selection structures in Java.

Selection structures allow a program to make decisions.

The focus is on:

- `if`
- `if-else`
- `else-if`
- `switch`
- relational operators
- logical operators

Selection structures are used when an object's behavior depends on conditions.

---

## 2. Control Structures in Java

Java programs use three main kinds of control structures:

### Sequence

Statements execute one after another.

### Selection

The program chooses between alternatives.

Examples:

```java
if
if-else
switch
```

### Repetition

The program repeats statements.

Loops are introduced later in the course.

---

## 3. The if Statement

An `if` statement executes code only if a condition is true.

Example:

```java
public String status()
{
  String status = "Adult";

  if (getAge() < 18)
  {
    status = "Child";
  }

  return status;
}
```

The condition must be a boolean expression.

---

## 4. The if-else Statement

`if-else` chooses between two alternatives.

Example:

```java
public String status()
{
  if (getAge() < 18)
  {
    return "Child";
  }
  else
  {
    return "Adult";
  }
}
```

One branch executes if the condition is true.
The other branch executes if the condition is false.

---

## 5. Cascading else-if

`else-if` handles multiple alternatives.

Example:

```java
public String status()
{
  if (getAge() < 13)
  {
    return "Child";
  }
  else if (getAge() < 20)
  {
    return "Teenager";
  }
  else
  {
    return "Adult";
  }
}
```

Conditions are checked from top to bottom.

The first matching condition is executed.

---

## 6. Relational Operators

Relational operators compare values.

| Operator | Meaning |
|---|---|
| `>` | greater than |
| `<` | less than |
| `>=` | greater than or equal |
| `<=` | less than or equal |
| `==` | equal |
| `!=` | not equal |

Example:

```java
if (x >= 10)
{
  // ...
}
```

Relational operators return boolean values.

---

## 7. Logical Operators

Logical operators combine boolean expressions.

| Operator | Meaning |
|---|---|
| `&&` | AND |
| `||` | OR |
| `!` | NOT |

Example:

```java
if (x >= 10 && x < 100)
{
  // x is a two-digit number
}
```

Example:

```java
if (!isTwoDigit)
{
  // ...
}
```

Logical operators are important when behavior depends on multiple conditions.

---

## 8. Boolean Expressions

A boolean expression evaluates to either:

- `true`
- `false`

Examples:

```java
x > 10
```

```java
age < 18
```

```java
email != null
```

Boolean expressions are central to selection structures.

---

## 9. Comparing Primitive Types

Primitive values are compared using relational operators.

Example:

```java
if (x == 7)
{
  // ...
}
```

Example:

```java
if (x != 7)
{
  // ...
}
```

This works correctly for primitive types such as:

- `int`
- `double`
- `char`
- `boolean`

---

## 10. Comparing Strings

Strings are objects.

Do not use `==` to compare strings.

Avoid:

```java
if (s == "Bob")
{
  // wrong approach
}
```

Use `equals()` instead.

Correct:

```java
if (s.equals("Bob"))
{
  // correct approach
}
```

Example:

```java
if (!s.equals("Bob"))   // s is not equal to "Bob"
{
  // ...
}
```

After Session 2 and Session 4, `equals()` should always be used for string comparison.

---

## 11. null Checks

A reference may be `null`.

Selection structures are often used to check for `null`.

Example:

```java
if (email != null)
{
  s += ", email=" + email;
}
else
{
  s += ", no email";
}
```

This avoids using or calling methods on `null` references.

---

## 12. switch Statements

A `switch` statement handles multiple alternatives.

Example:

```java
public String getDayOfWeek()
{
  switch(day)
  {
    case 1:
      return "Monday";
    case 2:
      return "Tuesday";
    case 3:
      return "Wednesday";
    default:
      return "Unknown";
  }
}
```

`switch` is useful when selecting between many fixed values.

---

## 13. toString() and Selections

Selection structures are often used in `toString()` methods.

Example:

```java
public String toString()
{
  String s = name + ", semester=" + semester;

  if (email != null)
  {
    s += ", email=" + email;
  }
  else
  {
    s += ", no email";
  }

  return s;
}
```

The object's output changes depending on its state.

---

## 14. Responsibility and Selections

Selection logic should usually belong inside the object.

Example:

Good:

```java
person.isAdult()
```

Less good:

```java
person.getAge() >= 18
```

The object should be responsible for decisions based on its own data.

---

## 15. Testing Selection Logic

Selection logic should be tested carefully.

Example:

```java
@Test void childStatus()
{
  Person p = new Person("Bob", 10);

  assertEquals("Child", p.status());
}
```

Important test cases include:

- normal cases
- boundary values
- alternative branches

4. Writing overlapping conditions
5. Writing impossible conditions
6. Forgetting `else`
7. Calling methods on `null`
