# Kapitel 12 – Design- og implementationsopgave

## 1. Introduktion

Dette kapitel giver en opgave, der træner design og implementation.

Formålet er at træne:

- analyse af en problemstilling  
- design af klasser  
- implementering  
- test  
- mundtlig forklaring  

---

## 2. Opgave: Library-system

Du skal modellere et simpelt bibliotekssystem.

Systemet består af:

- Book  
- Library  

---

## 3. Krav

### Book

- har titel (String)  
- har forfatter (String)  
- må ikke være null eller tom  

Metoder:
- getTitle()  
- getAuthor()  
- equals(...)  

---

### Library

- indeholder flere Book-objekter  

Metoder:
- addBook(Book book)  
- removeBook(Book book)  
- contains(Book book)  
- getNumberOfBooks()  

---

## 4. Designkrav

- ingen null værdier  
- korrekt invariant  
- encapsulation (ingen direkte adgang til liste)  
- tydeligt ansvar  

---

## 5. Testkrav

Du skal skrive tests for:

### Book
- equals (samme/forskellige værdier)  

### Library
- tilføj bog  
- fjern bog  
- contains  
- antal bøger  

### Grænsetilfælde
- tom samling  
- null input  

---

## 6. Eksempel på test

```java
@Test
void addBook_increasesSize() {
  Library lib = new Library();
  Book book = new Book("Title", "Author");

  lib.addBook(book);

  assertEquals(1, lib.getNumberOfBooks());
}
```

---

## 7. Arbejdsproces

1. Læs opgaven

3. Identificér relationer  
4. Lav testidéer  
5. Skriv tests

---

## 8. Mundtlig del (som til eksamen)

Du skal kunne forklare:

- dit design  
- dine valg af relationer  
- dine invariants  
- dine tests  

Eksempler på spørgsmål:

- Hvorfor valgte du denne løsning?  
- Hvordan sikrer du korrekt brug af klassen?  
- Hvordan tester du edge cases (grænsetilfælde)?  

---

## 9. Vurderingskriterier

Der lægges vægt på:

- korrekt design  
- korrekt implementering  
- systematisk test  
- evne til at forklare
