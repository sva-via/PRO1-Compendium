# Chapter 7 – Arrays

## 1. Introduction

Session 7 introduces arrays.

Arrays are used to store collections of values.

The focus is on:

- arrays
- fixed-size collections
- indexes
- capacity versus size
- storing multiple values
- arrays of primitive values and objects

Arrays are the first collection structure introduced in the course.

---

## 2. Why Arrays?

Sometimes a class must store many values.

Example:

- grades
- names
- temperatures
- tasks

Using many separate variables is not scalable.

Less good:

```java
private int grade1;
private int grade2;
private int grade3;
private int grade4;
```

Better:

```java
private int[] grades;
```

An array stores many values of the same type.

---

## 3. Arrays as Objects

An array is an object.

A variable stores a reference to the array.

Example:

```java
private int[] grades;
```

Initially:

```java
grades == null
```

The array object must be created before use.

---

## 4. Creating Arrays

Arrays are created using `new`.

Example:

```java
grades = new int[4];
```

This creates an array with:
- capacity 4
- indexes from `0` to `3`

Arrays always have fixed length.

---

## 5. Array Indexes

Array indexes start at `0`.

Example:

```text
Index:   0   1   2   3
Value:  12   7  10   4
```

Accessing elements:

```java
grades[0]
grades[1]
```

Indexes must always stay within bounds.

---

## 6. Capacity and Size

Session 7 introduces an important distinction.

### Capacity

The capacity is the array length.

Example:

```java
grades.length
```

### Size

The size is the number of stored elements.

Example:

```java
private int size;
```

The array may have unused positions.

Example:

```text
Capacity = 10
Size = 3
```

Only the first three positions contain meaningful values.

---

## 7. A GradeList Class

Example:

```java
public class GradeList
{
  private int[] grades;
  private int size;

  public GradeList(int capacity)
  {
    grades = new int[capacity];
    size = 0;
  }
}
```

The class stores:

- the array itself
- the current number of added grades

---

## 8. Accessing Array Elements

Elements are accessed using square brackets.

Example:

```java
return grades[index];
```

Example setter:

```java
grades[size] = grade;
```

Arrays provide direct access by index.

---

## 9. Adding Elements

Example:

```java
public void addGrade(int grade)
{
  grades[size] = grade;
  size++;
}
```

The new element is placed at index `size`.

Then `size` is incremented.

The next free position moves forward.

---

## 10. Checking Capacity

Before adding elements, the class must ensure that space exists.

Example:

```java
public boolean isFull()
{
  return size == grades.length;
}
```

Example:

```java
if (isFull())
{
  throw new IllegalStateException(
      "Grade list is full");
}
```

The object protects itself from invalid operations.

---

## 11. Array Length

Arrays store their capacity in a field called `length`.

Example:

```java
grades.length
```

Important:

- `length` is not a method
- no parentheses are used

Correct:

```java
grades.length
```

Wrong:

```java
grades.length()
```

---

## 12. Arrays of Primitive Types

Arrays can store primitive values.

Examples:

```java
int[] grades;
double[] temperatures;
char[] letters;
```

Primitive arrays store values directly.

---

## 13. Arrays of Objects

Arrays can also store references to objects.

Examples:

```java
String[] names;
Person[] persons;
```

The array stores references.

The objects themselves exist elsewhere in memory.

---

## 14. Default Values in Arrays

Array elements automatically receive default values.

Examples:

| Type | Default Value |
|---|---|
| `int` | `0` |
| `double` | `0.0` |
| `boolean` | `false` |
| references | `null` |

Example:

```java
new int[4]
```

creates:

```text
0 0 0 0
```

---

## 15. Validation and Arrays

Array operations should validate indexes.

Example:

```java
public int getGrade(int index)
{
  if (index < 0 || index >= size)
  {
    throw new IllegalArgumentException(
        "Index out of bounds: " + index);
  }

  return grades[index];
}
```

The object protects itself from illegal access.

---

## 16. Removing Elements Logically

Sometimes elements are removed logically rather than physically.

Example:

```java
public void removeLastGrade()
{
  if (size == 0)
  {
    throw new IllegalStateException(
        "No grades stored");
  }

  size--;
}
```

The array itself is unchanged.

Only `size` changes.

---

## 17. Clearing an Array Structure

Example:

```java
public void clear()
{
  size = 0;
}
```

The array still exists.

The object simply considers it empty.

---

## 18. Arrays and Responsibility

The array is an implementation detail.

Other classes should not manipulate the array directly.

Good design:

```java
gradeList.addGrade(12)
```

instead of exposing the array itself.

The class should protect:

- indexes
- capacity
- invariants

---

## 19. Typical Beginner Mistakes

Common mistakes:

1. Forgetting to create the array with `new`
2. Confusing `size` and `length`
3. Accessing illegal indexes
4. Forgetting that indexes start at `0`
5. Using `length()` instead of `length`
6. Forgetting to update `size`
7. Accessing unused array positions

---

- Why must indexes be validated?
- What is the difference between arrays of primitives and arrays of objects?
- Why is the array usually private?

---

## Summary

Session 7 introduces arrays as fixed-size collections.

Important ideas include:

- arrays store multiple values
- arrays have fixed length
- indexes start at `0`
- capacity and size are different concepts
- arrays may store primitives or object references
- arrays require validation and bounds checking
- the array structure should be encapsulated inside the class

Arrays are an important foundation for later work with loops, resizing, and collections.
