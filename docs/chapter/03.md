# Chapter 3 – Classes

## 1. Introduction

Session 3 continues the work with classes and objects from Sessions 1 and 2.

The focus is now on:

- class design
- constructors
- primitive types
- UML class diagrams
- object methods
- designing meaningful classes

The goal is not only to write code, but to design classes with clear responsibilities.

---

## 2. A Class Describes Objects

A class is a model for creating objects.

Example:

```java
public class Rectangle
{
  private double length;
  private double width;

  public Rectangle(double length, double width)
  {
    this.length = length;
    this.width = width;
  }
}
```

The class describes:

- which data objects store
- which operations objects can perform

Objects created from the class are called instances.

---

## 3. Instance Variables (Fields)

Instance variables store the state of an object.

Example:

```java
private double length;
private double width;
```

Each object has its own values.

Example:

```java
Rectangle r1 = new Rectangle(10, 20);
Rectangle r2 = new Rectangle(5, 8);
```

`r1` and `r2` store different values.

---

## 4. Constructors

Constructors initialize objects.

Example:

```java
public Rectangle(double length, double width)
{
  this.length = length;
  this.width = width;
}
```

The constructor ensures that the object starts with an initial state.

Objects are created using `new`:

```java
Rectangle rect = new Rectangle(10.0, 20.0);
```

---

## 5. The Purpose of Constructors

The purpose of a constructor is to initialize all instance variables.

Example:

```java
public Rectangle()
{
  setLength(1.0);
  setWidth(1.0);
}
```

A constructor should leave the object in a meaningful state.

---

## 6. Methods

Methods define the behavior of an object.

### Accessor Methods (Getters)

Accessor methods return information.

Example:

```java
public double getLength()
{
  return length;
}
```

### Mutator Methods (Setters)

Mutator methods modify the object's state.

Example:

```java
public void setWidth(double width)
{
  this.width = width;
}
```

---

## 7. Calculated Methods

Some methods calculate values based on the object's state.

Example:

```java
public double getArea()
{
  return length * width;
}
```

The `Rectangle` object is responsible for calculating its own area.

## 8. UML Class Diagrams

## 10. char

The `char` type stores a single Unicode character.

Example:

```java
char gender = 'M';
```

Characters use single quotes.

Strings use double quotes.

Example:

```java
String name = "Bob";
char gender = 'M';
```

---

## 11. Choosing Appropriate Types

Choosing types is part of class design.

Example:

```java
private String phone;
```

Phone numbers are often better represented as `String` values because:

- they are not used in calculations
- they may contain country codes
- they may begin with zero

Good design means choosing types that represent the domain correctly.

---

## 12. Default Constructors

If no constructor is written, Java provides a default constructor.

Example:

```java
Rectangle rectangle = new Rectangle();
```

The default constructor:

- takes no arguments
- assigns default values

Default values include:

- `0` for integers
- `0.0` for doubles
- `false` for booleans
- `null` for references

However, default values are not always meaningful.

Example:
- a rectangle with width `0.0` may not make sense

---

## 13. Floating Point Numbers

Floating point numbers are approximate.

Example:

```java
double value = 0.1 + 0.2;
```

Because of precision issues, tests use an epsilon value.

Example:

```java
private static final double EPSILON = 0.00001;
```

```java
assertEquals(0.3, value, EPSILON);
```

---

## 14. Object Methods

All classes inherit methods from the `Object` class.

Important methods include:

- `toString()`
- `equals()`

These methods already exist even if you do not implement them yourself.

---

## 15. toString()

`toString()` returns a textual representation of an object.

Example:

```java
public String toString()
{
  return name + ", semester=" + semester;
}
```

This makes objects easier to:

- display
- debug
- test

After Session 3, relevant domain classes should implement `toString()`.

---

## 16. equals()

`equals()` compares object contents.

Example:

```java
person1.equals(person2)
```

This is different from:

```java
person1 == person2
```

`==` compares references.

`equals()` compares meaning or contents.

After Session 3, value-like classes should implement `equals()`.

---

## 17. Testing Classes

Testing remains an important part of the course.

Example:

```java
@Test void stateAfterZeroArgsConstructor()
{
  Rectangle rectangle = new Rectangle();

  assertEquals(1.0, rectangle.getLength(), EPSILON);
  assertEquals(1.0, rectangle.getWidth(), EPSILON);
}
```

Tests should verify:

- state after construction
- method behavior
- calculated values

## 18. Typical Beginner Mistakes

Common mistakes:

1. Forgetting to initialize instance variables
2. Confusing fields and local variables
3. Using incorrect data types
4. Forgetting that `==` compares references
5. Writing classes without clear responsibility
6. Ignoring meaningful default states
