# Kapitel 11 – Mini-projekt

## 1. Introduktion

Nu samler vi det, du har lært indtil videre:

- klasser og objekter  
- konstruktører og invariant  
- metoder og ansvar  
- relationer mellem objekter  
- samlinger (1–many)  
- equals og test  

I dette mini-projekt skal du modellere et lille system og teste det.

---

## 2. Opgave: Playlist-system

Du skal implementere et simpelt system bestående af:

- Song  
- Time  
- Playlist  

---

## 3. Krav

### Time
- repræsenterer varighed i sekunder  
- må ikke være negativ  

### Song
- har titel (String)  
- har varighed (Time)  
- må ikke have null værdier  

Metoder:
- getDurationInSeconds()  
- equals(...)  

---

### Playlist
- indeholder flere Song-objekter  

Metoder:
- addSong(Song song)  
- removeSong(Song song)  
- getNumberOfSongs()  
- getTotalDuration()  
- contains(Song song)  

---

## 4. Designkrav

- ingen null værdier  
- korrekt invariant  
- tydeligt ansvar  
- ingen direkte adgang til interne lister  

---

## 5. Testkrav

Du skal skrive tests for:

### Song
- equals (samme/forskellige værdier)  

### Playlist
- tilføj sang  
- fjern sang  
- total varighed  
- contains  

### Grænsetilfælde
- tom playlist  
- null input  

---

## 6. Eksempel på test

```java
@Test
void addSong_increasesSize() {
  Playlist playlist = new Playlist();
  Song song = new Song("Test", new Time(120));

  playlist.addSong(song);

  assertEquals(1, playlist.getNumberOfSongs());
}
```
