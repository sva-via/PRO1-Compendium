# Chapter 16 – GUI (Step 1): JavaFX Layout and Structure

## 1. Introduction

Session 16 introduces graphical user interfaces (GUI).

Until now, applications have focused on:

- domain objects
- responsibility
- persistence
- testing
- object collaboration

Session 16 adds:

> graphical interaction with users

The focus is on:

- JavaFX
- GUI structure
- scenes and stages
- FXML
- controls
- containers
- ViewHandler
- application structure

The goal is not advanced GUI programming.

The goal is:

> designing GUI applications while preserving object-oriented responsibility.

---

## 2. What Is a GUI?

GUI means:

```text
Graphical User Interface
```

Examples:

- buttons
- labels
- text fields
- windows
- tables

GUI applications allow users to interact visually.

Example:

```text
+-----------------------+
| Name: [___________]   |
|                       |
| [ OK ]                |
|                       |
| Status message        |
+-----------------------+
```

GUI becomes another responsibility layer.

Model objects still remain important.

---

## 3. GUI Structure

Session 16 introduces a GUI structure based on JavaFX.

Conceptual structure:

```text
Main
 ↓

MyApplication
 ↓

ViewHandler
 ↓

FXML
 ↓

Controls
```

Responsibilities remain separated.

GUI code should not replace model responsibility.

---

## 4. JavaFX Application Structure

JavaFX applications typically contain:

### Main

Responsible for:

- starting JavaFX

Example:

```java
public class Main
{
  public static void main(String[] args)
  {
    Application.launch(
        MyApplication.class);
  }
}
```

---

### MyApplication

Responsible for:

- starting the application
- creating the view

Example:

```java
public class MyApplication
    extends Application
{
  public void start(
      Stage primaryStage)
  {
    ViewHandler view =
        new ViewHandler();

    view.start(primaryStage);
  }
}
```

---

### ViewHandler

Responsible for:

- loading views
- creating scenes
- opening windows
- switching windows later

Responsibility remains focused.

---

## 5. Stage

JavaFX introduces:

```text
Stage
```

A Stage represents:

> a window

Example:

```text
+-----------------------+
| My Window             |
|                       |
| GUI content           |
|                       |
+-----------------------+
```

The Stage controls:

- title
- width
- height
- visibility

Example:

```java
primaryStage.setTitle(title);
```

```java
primaryStage.show();
```

---

## 6. Scene

JavaFX introduces:

```text
Scene
```

A Scene represents:

> GUI content inside a window

Example:

```text
Stage
 └── Scene
      └── GUI components
```

Example:

```java
Scene currentScene;
```

The Scene manages GUI elements.

---

## 7. Scene Graph

JavaFX GUI elements form a hierarchy.

Example:

```text
VBox
├── TextField
└── HBox
     ├── Button
     └── Label
```

This hierarchy is called:

```text
Scene Graph
```

GUI design becomes object collaboration.

Objects contain other objects.

---

## 8. FXML

FXML describes GUI structure.

Example:

```xml
<VBox>

  <children>

    <TextField/>

    <Button text="OK"/>

  </children>

</VBox>
```

FXML describes:

- controls
- layout
- hierarchy

FXML separates:

```text
GUI structure
```

from:

```text
Java implementation
```

This supports responsibility separation.

---

## 9. Controls

Controls are GUI components users interact with.

Examples:

```text
Button
```

```text
TextField
```

```text
Label
```

Example:

```xml
<Button text="OK"/>
```

Example:

```xml
<TextField/>
```

Controls provide interaction.

---

## 10. Containers

Containers organize controls.

Examples:

### VBox

Places elements vertically.

Example:

```text
Button

TextField

Label
```

---

### HBox

Places elements horizontally.

Example:

```text
Button  Label
```

Containers help organize layout.

---

## 11. Root Node

FXML begins with one root element.

Example:

```xml
<VBox>

</VBox>
```

The root node becomes:

> top-level GUI container

Everything belongs inside the root.

Example:

```text
VBox
├── Button
├── Label
└── TextField
```

GUI structure becomes hierarchical.

---

## 12. Loading FXML

ViewHandler loads FXML.

Example idea:

```java
FXMLLoader loader =
    new FXMLLoader();

loader.setLocation(
    getClass()
    .getResource(fxmlFile));

root = loader.load();
```

Responsibility:

```text
FXML file
→ GUI object hierarchy
```

ViewHandler creates GUI objects.

---

## 13. Window Title

FXML root nodes may contain:

```xml
userData="Simple GUI"
```

Example:

```xml
<VBox
 userData="Simple GUI">
```

Later:

```java
root.getUserData()
```

Window title becomes:

```text
Simple GUI
```

Responsibility remains centralized.

## 14. Width and Height

FXML may specify dimensions.

Example:

```xml
prefWidth="250"
```

Example:

```xml
prefHeight="115"
```

ViewHandler uses dimensions.

Example:

```java
primaryStage.setWidth(
    root.getPrefWidth());

primaryStage.setHeight(
    root.getPrefHeight());
```

GUI structure controls appearance.

## 15. CSS Styling

JavaFX supports CSS.

Example:

```css
.label
{
  -fx-text-fill: red;

  -fx-font-weight: bold;

  -fx-font-size: 20px;
}
```

FXML:

```xml
<stylesheets>

<String fx:value=
"View1.css"/>

</stylesheets>
```

CSS separates:

```text
Appearance
```

from:

```text
Behavior
```

Responsibility remains separated.

## 16. GUI Responsibility

Good responsibility:

Model:

```text
Business logic
```

GUI:

```text
Presentation
```

Less good:

```text
GUI calculates domain logic
```

Better:

```text
GUI asks model
```

Example:

Less good:

```java
buttonPressed()
{
  // calculate grades
}
```

Better:

```java
buttonPressed()
{
  gradeList.getAverage();
}
```

Responsibility remains central.
