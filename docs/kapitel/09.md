# Kapitel 9 – Samlinger af objekter (1–many relationer)

## 1. Introduktion

I kapitel 8 arbejdede vi med relationer mellem to objekter.

Men i mange situationer har vi ikke kun ét objekt – men **flere**.

Eksempler:

- En Playlist har mange Songs  
- En Person kan have flere adresser  
- En klasse har mange studerende  

Dette kaldes en **1–many relation**.

---

## 2. Fra ét objekt til mange

Tidligere:

```java
private Song song;
```

Nu:

```java
private ArrayList<Song> songs;
```

👉 Vi går fra én reference til en samling.

---

## 3. Eksempel: Playlist

```java
import java.util.ArrayList;

public class Playlist {

  private ArrayList<Song> songs;

  public Playlist() {
    songs = new ArrayList<>();
  }

  public void addSong(Song song) {
    if (song == null) {
      throw new IllegalArgumentException();
    }
    songs.add(song);
  }

  public int getNumberOfSongs() {
    return songs.size();
  }
}
```

---

## 4. Invariant i samlinger

Når vi arbejder med samlinger, opstår nye regler:

- elementer må ikke være null  
- samlingen skal være konsistent  
- evt. ingen dubletter  

👉 Klassen skal selv håndhæve dette.

---

## 5. Test af samlinger

```java
@Test
void addSong_increasesSize() {
  Playlist playlist = new Playlist();
  Song song = new Song("Test", new Time(120));

  playlist.addSong(song);

  assertEquals(1, playlist.getNumberOfSongs());
}
```

---

## 6. Testidéer

### Normale tilfælde
- tilføj ét element  
- tilføj flere elementer  

### Grænsetilfælde
- tom samling  
- mange elementer  

### Ugyldige input
- null  

---

## 7. Iteration (gennemløb)

For at arbejde med alle elementer:

```java
public int getTotalDuration() {
  int sum = 0;

  for (Song song : songs) {
    sum += song.getDurationInSeconds();
  }

  return sum;
}
```

---

## 8. Designovervejelser

Spørg:

- må der være dubletter?  
- må rækkefølgen ændres?  
- må elementer fjernes?  

👉 Det er designbeslutninger.

---

## 9. Encapsulation

Vi bør ikke give direkte adgang til listen:

❌ Dårligt:

```java
public ArrayList<Song> getSongs() {
  return songs;
}
```

✔️ Bedre:

- returnér kopi  
- eller giv kontrollerede metoder
