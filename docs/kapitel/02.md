## 2. String Is a Class

`String` is not a primitive type.

`String` is a class.

Example:

```java
String name = "Ada";
```

The variable does not contain the text itself.
The variable contains a reference to a `String` object.

Strings provide methods.

Example:

```java
String name = "Ada Lovelace";
int length = name.length();
```

---

## 3. Concatenating Strings

Strings can be combined using the `+` operator.

Example:

```java
public String getFullName()
{
  return firstName + " " + lastName;
}
```

Example test:

```java
@Test void fullNameIsCombinedCorrectly()
{
  Name name = new Name("Ada", "Lovelace");
  assertEquals("Ada Lovelace", name.getFullName());
}
```

---

## 4. References

Object variables store references.

Example:

```java
Name n1 = new Name("Ada", "Lovelace");
Name n2 = new Name("Ada", "Lovelace");
Name n3 = n2;
```

Important:
- `n1` and `n2` refer to different objects
- `n2` and `n3` refer to the same object

A reference tells the program where the object is located.

---

## 5. The Value null

A reference variable may contain `null`.

`null` means:
- the variable does not refer to an object
- there is no object

Example:

```java
Name name = null;
```

Calling a method on `null` causes an exception.

Example:

```java
Name name = null;
name.getFullName();
```

This causes a `NullPointerException`.

---

## 6. Testing Exceptions

JUnit can test that exceptions are thrown.

Example:

```java
@Test void callingMethodOnNullThrowsException()
{
  Name name = null;

  assertThrows(NullPointerException.class,
      () -> name.getFullName());
}
```

## 7. Comparing Objects

Primitive values are compared using `==`.

Example:

```java
int x = 5;
int y = 5;

x == y
```

Objects are different.

For objects:
- `==` compares references
- `equals()` compares contents

Example:

```java
String s1 = "Bob";
String s2 = "Bob123".substring(0, 3);
```

Correct comparison:

```java
s1.equals(s2)
```

Avoid:

```java
s1 == s2
```

After Session 2, `equals()` should always be used for comparing strings.

## 9. Constructors with Different Parameters

A class may have multiple constructors.

Example:

```java
public Student(String name, int semester, String email)
{
  this.name = name;
  this.semester = semester;
  this.email = email;
}

public Student(String name)
{
  this.name = name;
}
```

Different constructors allow different ways to create objects.

---

## 10. Constructor Delegation with this(...)

Constructors can call other constructors.

Example:

```java
public Student(String name)
{
  this(name, 1, null);
}
```

Advantages:
- avoids duplicated code
- ensures consistent initialization
- improves readability

After Session 2, constructor delegation using `this(...)` is preferred when constructors share logic.

---

## 11. toString()

Objects can provide a string representation using `toString()`.

Example:

```java
public String toString()
{
  return name + ", semester=" + semester;
}
```

This makes objects easier to display and test.

Example test:

```java
@Test void toStringAfter3ArgsConstructor()
{
  Student s = new Student("Bob", 3, "bob@builder.dk");

  assertEquals(
      "Bob, semester=3, email=bob@builder.dk",
      s.toString());
}
```

## 12. Typical Beginner Mistakes

Common mistakes:
1. Confusing an object with a reference variable
2. Calling methods on `null`
3. Using `==` for comparing strings
4. Forgetting that objects can share references
5. Duplicating constructor logic instead of using `this(...)`
