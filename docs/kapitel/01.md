# Kapitel 1 – Hvad er et objekt?

## 1. Introduktion

Dette kapitel handler om det mest grundlæggende spørgsmål i objektorienteret programmering: **Hvad er et objekt?**

I PRO1 er målet ikke først og fremmest at lære Java som sprog, men at lære at **modellere virkeligheden i software**.

Et objekt er en model af et begreb fra et domæne.

---

## 2. Objekt vs. variabel

En variabel er et sted i programmet, hvor vi gemmer en værdi.

```java
double celsius = 20.2;
```

Et objekt repræsenterer derimod et begreb med:
- tilstand (state)
- adfærd (metoder)
- ansvar

```java
Temperature t1 = new Temperature(20.2);
```

- `t1` er en variabel (reference)
- objektet er instansen af `Temperature`

---

## 3. Klassen som model

```java
public class Temperature
{
  private double celsius;

  public Temperature(double celsius)
  {
    this.celsius = celsius;
  }

  public double getCelsius()
  {
    return celsius;
  }

  public double getKelvin()
  {
    return celsius + 273.15;
  }
}
```

Klassen modellerer begrebet temperatur.

---

## 4. State og adfærd

State:
```java
private double celsius;
```

Adfærd:
```java
public double getKelvin()
{
  return celsius + 273.15;
}
```

---

## 5. Invariant

En invariant er en regel om objektets tilstand, som altid skal være opfyldt.

Eksempel:
Temperaturen må ikke være under -273.15 °C.

---

## 6. Beskyttelse af invariant (idé)

Et objekt bør beskytte sig selv mod ugyldig tilstand.

```java
if (celsius < -273.15)
{
  // afvis værdien
}
```

Hvordan dette implementeres i Java, ser vi senere.

---

## 7. Designovervejelser

- Samler data og adfærd
- Giver ansvar
- Sikrer gyldig tilstand

---

## 8. Typiske fejl

1. Objekt = variabel
2. Adfærd uden for objektet
3. Ignorere regler

---

## 9. Testidéer

- Normal: 20
- Grænse: -273.15
- Ugyldig: under -273.15

---

## 10. Refleksion

- Hvad er et objekt?
- Hvad er ansvar?
- Hvad er en regel?

---

## Afslutning

Et objekt er:
- en model af et begreb
- state + adfærd
- ansvar + regler
